# 01 要求仕様書

| 版 | 日付 | 内容 |
|---|---|---|
| 0.1 | 2026-11-01 | 初版（たたき台） |

## 1. 目的

屋内で安定してホバリング・操縦できる小型クアッドコプターを、基板・筐体・ファームウェアまで一貫して自作する。
姿勢推定と姿勢制御を実装を通して理解し、設計の過程と根拠をポートフォリオとして公開する。

## 2. スコープ

**対象**
- 角度モード（セルフレベル）での手動操縦飛行
- Androidスマホのブラウザからの操縦
- 自作PCB（フレーム兼用）、3Dプリント製プロペラガード、Arduinoファームウェア

**対象外（将来拡張）**
- 高度維持（ToF）、位置保持（光学フロー）
- 屋外飛行、自律飛行、カメラ

## 3. 機能要求

| ID | 要求 | 検証方法 |
|---|---|---|
| REQ-F01 | 角度モードで飛行できること。スティックを中立にすると機体が水平に戻る | 飛行試験 |
| REQ-F02 | Androidスマホのブラウザ（Chrome）から、スロットル・ロール・ピッチ・ヨーの操作とアーム/ディスアームができること。専用アプリのインストールは不要とする | 動作試験 |
| REQ-F03 | 通信が500ms以上途絶したら、モーター出力を下げて1秒以内に停止すること | 通信切断試験 |
| REQ-F04 | 電池電圧（負荷時）が3.5Vを下回ったら警告し、3.3Vを下回ったら出力を下げて停止すること | 安定化電源での試験 |
| REQ-F05 | アームは「スロットル最小」かつ「機体が水平±10°以内」のときだけ受け付けること | 動作試験 |
| REQ-F06 | 機体の傾きが60°を超えたら（転倒・墜落とみなし）モーターを即時停止すること | 手持ち試験（プロペラなし） |
| REQ-F07 | 姿勢角と電池電圧をスマホ画面に表示すること。USBシリアルで制御ログを出力できること | 動作試験 |
| REQ-F08 | USB経由でファームウェアを書き込めること | 書込み試験 |

## 4. 性能要求

| ID | 要求 | 検証方法 |
|---|---|---|
| REQ-P01 | 総重量60g以下（100g未満の余裕を確保） | 実測 |
| REQ-P02 | 推力重量比2.0以上 | 推力試験 |
| REQ-P03 | 飛行時間4分以上（ホバリング） | 飛行試験 |
| REQ-P04 | ホバリング中のロール・ピッチ角の変動が±3°以内 | 飛行ログ解析 |
| REQ-P05 | 内側の角速度制御ループを500Hz以上で回すこと | ログのタイムスタンプ |
| REQ-P06 | 操作してから機体が反応するまでの遅延が100ms以下 | ログ解析 |
| REQ-P07 | 屋内10mの距離で操縦できること | 飛行試験 |

## 5. 機構要求

| ID | 要求 | 検証方法 |
|---|---|---|
| REQ-M01 | 全プロペラにガードを付けること | 目視 |
| REQ-M02 | 外形はガード込みで150mm角以内 | 実測 |
| REQ-M03 | バッテリーを工具なしで交換できること | 動作確認 |
| REQ-M04 | 高さ1mから床に落ちても、ガード以外が壊れないこと（目標値） | 落下試験 |

## 6. 制約条件

| ID | 制約 |
|---|---|
| C-01 | 無線は技適取得済みのモジュールを使う（電波法対応） |
| C-02 | ファームウェアはArduino（arduino-esp32）で開発する |
| C-03 | 設計ツール：基板はKiCad、筐体はFusion 360 |
| C-04 | 部品はJLCPCB/LCSCで実装できるものを優先する（Basic Partsを優先してコストを下げる） |
| C-05 | 予算：目標1.5万円（試作2回分を含む） |
| C-06 | 期間：できるだけ短く（目標8週間） |
| C-07 | 成果物はGitHubで公開する（ライセンスはMIT） |

## 7. 安全要求

- LiPoは専用充電器で充電し、保管・充電時は耐火袋に入れる
- プロペラを付けた試験は、ファームウェアのフェイルセーフ（REQ-F03/F04/F06）を確認してから行う
- 初めての飛行は人がいない広い部屋で、低い高度から始める
