## Phase 1で確認すること

1. **推力試験**：モーター1個の推力と電流を、スロットル10%刻みで測る（キッチンスケール＋電流計）。 → `tools/budget.py` を実測値で更新する
2. **電圧降下**：モーター4個を全開にしたときの電池電圧の最低値を測る。 → LDOの選定とブラウンアウト対策を判断する
3. **IMU**：SPIで読み出し、姿勢推定（相補フィルタ → Mahonyフィルタ）の出力をグラフで確かめる
4. **通信遅延**：スマホで操作してからESP32が受信するまでの時間を測る（REQ-P06）
