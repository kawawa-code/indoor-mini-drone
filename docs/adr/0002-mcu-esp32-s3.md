# ADR-0002 マイコン：ESP32-S3-WROOM-1

- 状態：決定（2026-11-01）

## 背景
スマホから操縦するために無線が必要。開発環境はArduino。国内で合法に使うには技適が必要。

## 選択肢
| 案 | 長所 | 短所 |
|---|---|---|
| A. ESP32-S3-WROOM-1 | デュアルコアなので通信と制御を分けられる。USBを内蔵。技適取得済み。Arduinoの対応が充実 | C3より数百円高い |
| B. ESP32-C3-MINI-1 | 安くて小さい。技適取得済み | シングルコアなので、Wi-Fi処理が制御周期を乱すおそれがある |
| C. STM32＋無線モジュール | 制御の実時間性が高い | 部品が2つになり、構成が複雑になる |

## 決定
A を採用する。

## 理由
- 制御ループ（Core 1）と通信（Core 0）を分けられ、REQ-P05（500Hz）を満たしやすい
- 開発ボード（DevKitC-1）で試作したコードを、ほぼそのまま自作基板に移せる
- コストの差は数百円で、安定性のメリットのほうが大きい
